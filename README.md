# 🤖 AI Chatbot


An intelligent conversational AI chatbot built using Large Language Models (LLMs) and modern Generative AI tools. This application allows users to ask questions and receive context-aware responses through a clean and interactive Streamlit web interface.

---

## 📌 Project Overview

This project demonstrates how to build an end-to-end AI chatbot using:

- 🤗 Hugging Face models and APIs
- ⚡ Mistral AI API
- 🦜 LangChain for LLM orchestration
- 🎨 Streamlit for the user interface
- 🔐 Environment variables for secure API key management

The chatbot can be used for:

- General question answering
- Educational assistance
- Technical interview preparation
- AI-powered customer support
- Productivity and research tasks

---

## ✨ Features

- 💬 Real-time conversational chatbot
- 🤖 Multiple LLM integrations
- 🔄 Prompt handling with LangChain
- 🎨 User-friendly Streamlit interface
- 🔐 Secure API key storage with `.env`
- ⚡ Fast response generation
- 📱 Responsive web interface
- 🚀 Easy deployment
- 🛠 Modular and extensible codebase
